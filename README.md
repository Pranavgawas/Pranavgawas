### 🌟 Featured Projects

#### 🏎️ 1. Vehicle Configurator — B2B Car Leasing Portal
> *One product idea, three production-grade stacks.* A full B2B portal for rental car companies to bulk-purchase, configure, customize, and invoice vehicles — built end-to-end as a C-DAC capstone project.

| Stack Component | Repository | Highlights |
| :--- | :--- | :--- |
| ⚛️ **React (Frontend)** | [VehicleConfigurator-react](https://github.com/Pranavgawas/VehicleConfigurator-react) | Vite + React, live on GitHub Pages |
| ☕ **Java Spring Boot 3 (Backend)** | [VehicleConfigurator-java](https://github.com/Pranavgawas/VehicleConfigurator-java) | JPA · MySQL · Maven · JUnit |
| 🔷 **.NET Core (Microservice)** | [VehicleConfigurator-dotnet](https://github.com/Pranavgawas/VehicleConfigurator-dotnet) | Entity Framework · SQL Server · Web API |

- **Key Functionality:** Browse vehicle models, modify interior/exterior/color/seats, place bulk orders, and generate PDF invoices wrapped in a Dockerized microservices architecture.
- 🔗 **Live Demo:** [pranavgawas.github.io/VehicleConfigurator-react](https://pranavgawas.github.io/VehicleConfigurator-react/)

<br/>
